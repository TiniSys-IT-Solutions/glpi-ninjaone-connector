# Contributing

Contributions are welcome through focused issues and pull requests.

## Before opening a pull request

1. Target the `main` branch and keep the change limited to one subject.
2. Never commit NinjaOne credentials, tokens, tenant payloads or private GLPI
   data.
3. Preserve compatibility with the versions documented in the README.
4. Validate synchronization changes against a disposable GLPI environment.
5. Document security-sensitive changes and their manual test coverage.

By contributing, you agree that your contribution is licensed under
GPL-3.0-or-later, the licence of this project.
