# Changelog

All notable public changes to GLPI NinjaOne Connector are documented here.

## [0.1.0] - 2026-09-03

### Added

- NinjaOne Services API connection using Client Credentials.
- Explicit organization, entity and location mappings.
- Minimal NinjaOne synchronization and advanced GLPI Agent portable mode.
- Scheduled synchronization, log retention and linked-computer information.

### Changed

- Establish the first clean public release baseline.
- Align licensing, ownership, security and contribution documentation with
  TiniSys IT Solutions standards.

### Security

- Limit the current connector scope to NinjaOne Monitoring.
- Document secret storage, least-privilege deployment and private reporting.
